# Latent-conditioned sampled pairwise MI recipes

These recipes train `ContrastivePairwiseFLO` or `SampledPairwiseBA` on feature
tensors generated by `LatentPairwiseCorrelatedGaussian`. By default, every
tensor contains five Gaussian variables with an exact 5-by-5
mutual-information matrix. Each batch creates ten independent contexts and
selects eight without replacement.

Run it with:

```bash
python recipes/LatentPairwiseCorrelatedGaussian/MI/train.py \
  recipes/LatentPairwiseCorrelatedGaussian/MI/hparams/train_flo.yaml
```

Run the non-contrastive Barber-Agakov estimator with:

```bash
python recipes/LatentPairwiseCorrelatedGaussian/MI/train.py \
  recipes/LatentPairwiseCorrelatedGaussian/MI/hparams/train_ba.yaml
```

The dataset—not the `DataLoader`—constructs batches because latent components
must be selected without replacement. Consequently, both loaders use
`batch_size: null` and a TensorDict pass-through collator. Increasing the
dataset `batch_size` beyond `latent_count` is invalid.

The context consumes part of the covariance prescribed by the target instead
of adding new covariance. The supplied matrix is therefore the exact
unconditional MI despite same-sequence pairs sharing context and
different-sequence pairs using independent contexts. After validation, the
recipe prints the accumulated learned 5-by-5 matrix beside that ground truth.
Positions not sampled during a validation stage are displayed as `nan`.

For a short smoke run:

```bash
python recipes/LatentPairwiseCorrelatedGaussian/MI/train.py \
  recipes/LatentPairwiseCorrelatedGaussian/MI/hparams/train_flo.yaml \
  --number_of_epochs=1 --train_batches=8 --valid_batches=2
```
